# 검증 범위

현재 기능은 공식 SDK 응답 유틸리티·평가 라이브러리·CLI·판단 호출 스킬이다.

- 질문별 Choice·Score·Noul 응답, 선택지·확률·점수 검증과 질문 버전 메타데이터를 확인한다. 검증 실패의 경로·코드와 거부된 값·외부 키의 비노출을 검사한다.
- SDK 호출의 실패·timeout·취소를 실제 SDK 오류로 구분한다. 호출자의 재시도·헤더·모델 옵션을 유지하고 사용량 미상을 보존한다. `observe`는 전달한 SDK 실행 함수만 한 번 호출하며 추가 재시도를 하지 않는다. 순수 검증·변환 함수는 호출하지 않는다.
- 배포 tarball을 빈 프로젝트에 설치해 타입 추론·CLI 실행·키 설정·평가를 확인한다.
- 에이전트 스킬 설치·갱신·제거가 기존 Codex·Claude 설정을 그대로 보존하는지 확인한다. 다른 스킬 파일이나 사용자가 수정한 파일은 덮어쓰지 않는다.
- 공식 SDK와 같은 유틸리티 산출물을 실제 Workers isolate와 Deno에서 실행한다.

`npm run check`, `npm test`, `npm run test:compat`로 검증한다. 모의 응답 검증과 런타임 호환성은 질문의 의미 정확도를 입증하지 않는다. 업무별 정답 사례·임계값·관측 데이터는 해당 프로젝트에서 평가한다.
